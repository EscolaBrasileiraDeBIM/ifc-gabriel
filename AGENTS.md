## Instruções gerais EBBIM

Ao iniciar ou retomar o trabalho, leia `.ebbim-instrucoes/AGENTS.md` e as
instruções específicas deste projeto. Quando as instruções compartilhadas forem
atualizadas, releia as instruções aplicáveis. A fonte compartilhada é o repositório
privado `EscolaBrasileiraDeBIM/ebbim-instrucoes`.
Se a cópia local não estiver disponível, informe a ausência e prepare-a conforme
o README desse repositório; um link remoto sozinho não carrega as instruções.
